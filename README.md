# budget-releases

Публичный канал релизов budget — сервиса семейного бюджета (веб-дашборд, Telegram-бот и приложение для ноутбука).
Исходного кода здесь нет: только готовые файлы релизов.

## Состав релиза

| Файл | Назначение |
|---|---|
| `webctl` | веб-дашборд, linux/amd64 |
| `botctl` | Telegram-бот, linux/amd64 |
| `pull-deploy.sh` | автообновление сервера до последнего релиза |
| `budget-web.service`, `budget-bot.service` | systemd-юниты сервисов |
| `budget-deploy.service`, `budget-deploy.timer` | systemd-юниты автообновления |
| `Budget-macos-arm64.zip` | приложение для Mac на Apple Silicon |
| `Budget-windows-amd64.zip` | приложение для Windows 10/11 |
| `SHA256SUMS` | контрольные суммы файлов выше |

Архивы «Source code» GitHub прикладывает к каждому релизу сам: в них только этот README.

## Приложение для ноутбука

Бюджет без сервера: данные хранятся только на вашем компьютере.

1. Откройте [последний релиз](https://github.com/dzhavoronkov/budget-releases/releases/latest)
   и скачайте архив: `Budget-macos-arm64.zip` (Mac на Apple Silicon — M1 и новее)
   или `Budget-windows-amd64.zip` (Windows 10/11).
2. Распакуйте архив. Mac: перенесите `Budget.app` в «Программы».
   Windows: положите `Budget.exe` в любую папку.
3. Приложение не подписано сертификатом Apple / Microsoft, поэтому первый запуск
   нужно разрешить один раз:
   - **macOS:** откройте `Budget.app` → «Готово» в предупреждении →
     «Системные настройки → Конфиденциальность и безопасность» → внизу
     «Всё равно открыть» → пароль.
   - **Windows:** в окне SmartScreen «Подробнее» → «Выполнить в любом случае».
     Если включён Smart App Control (Windows 11), он блокирует неподписанные
     приложения без возможности разрешить — запустить не получится.
   - **Windows без WebView2:** приложение предложит скачать Microsoft Edge
     WebView2 Runtime; установите и запустите снова.

Данные и бэкапы:

| | Данные | Бэкапы |
|---|---|---|
| macOS | `~/Library/Application Support/Budget` | `…/Budget/backups` |
| Windows | `%AppData%\Budget` | `%AppData%\Budget\backups` |

Бэкап снимается перед запуском новой версии и раз в сутки. Чтобы перенести бюджет
на другой компьютер, скопируйте папку `Budget` целиком при закрытом приложении.

Новая версия: приложение раз в сутки проверяет релизы и через 3 дня после выхода
показывает вверху страницы «Доступна версия X» — «Обновить» ставит её и перезапускает
приложение, «Пропустить» больше её не предлагает. Без вашего нажатия ничего не меняется.
На Mac обновление работает, только если `Budget.app` перенесён из «Загрузок»
(например, в «Программы»).

Откат: прежняя версия остаётся рядом — `Budget.prev.app` / `Budget.prev.exe`.
Закройте приложение, удалите новое и переименуйте прежнее обратно в `Budget.app` /
`Budget.exe`.

## Свой сервер

Установщик одной командой и инструкция для своего сервера — в работе, появятся здесь.
Уже поставленный сервер обновляется сам: `pull-deploy.sh` по таймеру раз в минуту
берёт последний релиз, сверяет `SHA256SUMS` и перезапускает сервисы.
